About the Lab

This is a home lab is designed to practice real-world networking, Linux administration, automation, and web server deployment.

Network Monitoring

Planned Grafana dashboard to track devices, uptime, and network activity.

Web Server

Personal website hosted locally and later deployed through NGiNX.

Reverse Proxy

NGINX will route traffic to different services from one Raspberry Pi.

Project Goals

  • Host a personal website on a Raspberry Pi
  • Configure NGINX as a reverse proxy
  • Build a network monitoring dashboard
  • Use Github to document progress
