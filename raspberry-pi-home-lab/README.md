# Raspberry Pi Home Lab 🚀

This project is a personal home lab built to practice real-world skills in networking,
Linux administration, and web server deployment.

## Overview

The goal of this project is to simulate a real server environment using a Raspberry Pi 4.
The lab includes a hosted website, planned reverse proxy setup, and a network monitoring dashboard.

## Features

- Personal website built with HTML & CSS
- Local web server using Python
- Planned NGINX reverse proxy configuration
- Planned Grafana monitoring dashboard
- Mobile-responsive design

## Tech Stack

- HTML & CSS
- Python (basic scripting)
- Linux (CLI)
- Git & GitHub
- Networking fundamentals (in progress)

## Project Status

- Web Server: Running locally
- NGINX: Not deployed
- Monitoring Dashboard: In progress
